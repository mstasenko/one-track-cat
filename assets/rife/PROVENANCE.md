# Reviewed RIFE and attribution inputs

`assets.json` records the exact member names, sizes and SHA-256 hashes of these
build inputs. The pack recipe also pins each archive and shipped payload.

- `rife-ir.zip` contains the qualified RIFE v4.25 packed-7 OpenVINO XML/BIN.
  Archive SHA-256: `912fea8a9a405799cbe122605da12d6e4b5330aec83a0e026910651cb34d39fa`.
  Published packed-7 ONNX source SHA-256:
  `65c57a5e4abb17ad67faf35054291ac53affab0506d509d2e66698f6ecd75584`.
  Source v4.25 archive SHA-256:
  `172fe975c1775134bb87108e4ec6d1a89e861cc5d3be2ac23bf08afe5ed626b8`.
  An independent OpenVINO 2025.3 reproduction preserved identical BIN bytes
  and equivalent XML except autogenerated names. Ordinary builds reuse the
  reviewed IR rather than silently reconverting it with a newer runtime.
  The original training-checkpoint/exporter revision was not retained; no
  stronger end-to-end source reproducibility claim is made.
- `notices.zip` preserves reviewed license/notice source files. The pack
  copies only the applicable pinned payloads, not every archived component.
  Archive SHA-256:
  `21b9b99d79af32fe66800fc68efb104367e1e93bf4092b6e6395eed4b48d5578`.
